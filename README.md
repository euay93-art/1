# 설야장 살인사건 (雪夜莊)

폭설로 고립된 강원도 산중 아트 레지던시에서 벌어진 살인을 파헤치는 **1인용 추리 게임**.
다섯 명의 용의자는 고정 대사가 아니라 **Claude가 연기하는 AI 캐릭터**다. 무엇이든 물어볼 수 있고,
각자 숨기는 것이 있으며, 진범은 끝까지 거짓말을 한다.

## 실행

```bash
npm start
```

터미널에 뜨는 주소(`http://localhost:4173`)를 브라우저에서 연다.

**API 키가 필요 없다.** 서버는 이미 로그인된 Claude Code CLI(`claude -p`)를 통해 호출하므로
Max/Pro 구독 인증을 그대로 쓴다. (`claude` 명령이 PATH에 있고 `claude auth` 로그인이 되어 있으면 된다.)

`index.html`을 파일로 바로 열어도 플레이는 가능하지만, 그 경우 AI가 꺼진 **각본 모드**로 돌아간다.
미리 쓰인 질문 버튼으로만 진행되며 자유 대화는 되지 않는다.

### 설정 (환경 변수)

| 변수 | 기본값 | 설명 |
|---|---|---|
| `PORT` | `4173` | 서버 포트 |
| `SEOLYA_MODEL` | `opus` | 용의자 연기 모델. 응답을 빠르게 하려면 `sonnet` |
| `SEOLYA_EFFORT` | `low` | 추론 강도 (`low`~`max`). 높이면 연기가 깊어지지만 느려진다 |
| `CLAUDE_BIN` | `claude` | Claude Code 실행 파일 경로 |

```bash
SEOLYA_MODEL=sonnet npm start   # 더 빠른 응답
```

## 게임 진행

1. **현장 조사** — 8개 장소에서 증거 28개를 찾는다. 일부 증거는 다른 증거를 먼저 확보해야 의미가 드러난다.
2. **심문** — 다섯 용의자에게 자유롭게 질문한다. 📎 버튼으로 확보한 증거를 눈앞에 들이밀 수 있다.
   치명적인 증거가 쌓이면 진범의 진술이 무너진다.
3. **사건 수첩** — 모은 증거, 인물, 그리고 증거로만 채워지는 타임라인을 본다.
4. **최종 추리** — 범인·흉기·트릭·동기·발자국의 정체를 진술한다. 채점 후 해결편이 공개된다.

행동 하나에 5분이 흐르고, 오후 3시에 경찰이 도착하면 강제로 최종 추리에 들어간다.
이미 찾은 증거를 다시 읽는 데는 시간이 들지 않는다.

## 구조

```
index.html            화면 구조
css/style.css         스타일
js/case.js            시나리오 데이터 (장소·증거·각본 대사·정답)
js/state.js           게임 상태와 localStorage 저장
js/ui.js              화면 전환, HUD, 눈, 타자기 효과
js/ai.js              AI 서버 연결 / 각본 모드 자동 전환
js/investigate.js     현장 조사
js/interrogate.js     심문과 증거 제시
js/notebook.js        사건 수첩
js/accuse.js          최종 추리와 채점
js/main.js            초기화
server/server.js      정적 서빙 + /api/ask
server/characters.js  AI 용의자의 인격·기억·거짓말 규칙
```

`server/characters.js`에는 진범이 실제로 한 일과 각 인물이 숨기는 비밀이 들어 있다.
이 파일은 서버에만 존재하며 브라우저로 내려가지 않는다. **먼저 플레이하고 싶다면 열지 말 것.**

의존성은 없다. Node 18 이상이면 된다.
